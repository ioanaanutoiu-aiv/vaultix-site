## Project Overview
Vaultix is a real-time data infrastructure platform for AI teams. The design features a dark, high-contrast aesthetic using a monospaced typeface with a neon yellow accent, emphasizing precision and technical credibility.

## Spacing System
- Section content padding (desktop): 156px (9.75em) — aligns with decorative border lines
- Nav inner padding: 176px (11em)
- Section inner padding: 52px (3.25em) for CTA

## Design Characteristics
- Sharp corners (no border radius)
- Decorative grid lines as section borders (1px solid #343434)
- Uppercase text throughout
- Halftone photo treatment on hero image
- Hexagonal/polygon decorative shapes in CTA
- Large "Vaultix" watermark text overlay in footer

## Sections
1. **Hero** — 2-column (image + bio text), navbar inside, decorative border lines
2. **CTA** — Centered "How it work" section with polygon decoratives and chart widget
3. **Footer** — 4-column navigation grid + "Stay Updated" with image watermark
